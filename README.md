## 🔁 Contribution Workflow (Fork → Pull Request)

1. **Fork** the original repository (**Fork → Create fork**).
2. Add **one file** named with your roll number, for example `577.md`.
3. **Commit** with a clear message, for example `Add 577 – Hit Galani`.
4. Open a **pull request** to `sbccas/sy-ai-2026-wall`, titled `577 – Hit Galani`.
5. Submit the pull request link on the course site (**Your account → Remote session → Part C**).

### Rules

- Add **only your own file** in the pull request. Do not change anyone else's file or the original README.
- Be kind and professional: the repository is public.
- Never share passwords, API keys or phone numbers.
